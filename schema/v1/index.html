schema/v1/

A suggested way forward for property packs in England. One worked proposal — not a standard, and endorsed by nobody.

This is a namespace base, not a document. The versioned artefacts published at this address are:

  • components.json — the component register: 27 components with permanent identifiers, supply codes, verification ceilings, expiry semantics and primary sources. CC-BY-4.0.
  • envelope.schema.json and envelope.ts — the provenance envelope: Envelope<T>, VerificationLevel, LegalStatus. CC-BY-4.0.
  • bundle.schema.json — the ukpp.pack.v1 handoff bundle, including owner-declared answers. CC-BY-4.0.
  • question.schema.json — the shape of a question definition, not the content of any bank. CC-BY-4.0.
  • rule-result.schema.json and rule-result.ts — an explainable determination and its evidence trail. CC-BY-4.0.
  • notification.schema.json and hook.schema.json — a reminder about a record, and an event sent to a subscribed partner. CC-BY-4.0.

The .ts files link to the blob view because GitHub Pages serves .ts as video/mp2t, so a browser downloads them rather than displaying them. Each has a JSON twin served here.

The reference validator and the conformance fixtures live in the repository, under schema/validator/ and schema/fixtures/. No version is tagged yet, and conformance is not yet claimable.
