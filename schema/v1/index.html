schema/v1/

A suggested way forward for property packs in England. One worked proposal — not a standard, and endorsed by nobody.

This is a namespace base, not a document. The versioned artefacts published at this address are:

  • components.json — the component register: 27 components with permanent identifiers, supply codes, verification ceilings, expiry semantics and primary sources. CC-BY-4.0.
  • envelope.ts — the provenance envelope: Envelope<T>, VerificationLevel, LegalStatus. CC-BY-4.0. Linked to the blob view because GitHub Pages serves .ts as video/mp2t, so a browser downloads it rather than displaying it.

Not written yet, and named so their absence is visible rather than implied: rule-result.ts, the question, bundle, notification and hook schemas, the reference validator and the conformance fixtures. No version is tagged, and conformance is not yet claimable.
